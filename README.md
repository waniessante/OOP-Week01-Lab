# Task 1 - Car Demo

In this task, I created a `Car` class and added different attributes and methods to represent a real car.

### Attributes

- Brand
- Color
- Speed
- Engine Status
- Fuel Level
- Gear
- Headlights Status
- Music Status

### Methods

- Start Engine
- Stop Engine
- Drive
- Move Fast
- Move Slow
- Move Left
- Move Right
- Turn On Headlights
- Play Music
- Turbo Mode
- Display State

The `Main.java` file creates two different car objects to show that each object has its own state.
