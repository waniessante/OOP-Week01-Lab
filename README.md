# Task 1 - Car Demo

## Description

A Car class was created to demonstrate object-oriented programming concepts.

### Attributes

- Brand
- Color
- Speed
- Engine Status
- Fuel Level
- Gear
- Headlights Status
- Music Status

### Behaviors

- Set Car Details
- Start Engine
- Stop Engine
- Drive
- Move Fast
- Move Slow
- Move Left
- Move Right
- Turn On Headlights
- Play Music
- Turbo Mode (Creative Feature)
- Display Current State

### Concepts Demonstrated

- Class
- Objects
- Attributes
- Methods
- Constructor
- Object Independence
- State Changes

# Task 2 - Calculator Demo

## Description

A Calculator class was created to perform different mathematical operations.

### Operations

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Average
- Maximum

### Edge Case

The calculator safely handles division by zero by displaying an error message instead of crashing.

### Concepts Demonstrated

- Methods
- Parameters
- Return Values
- Conditional Statements
- Mathematical Functions
